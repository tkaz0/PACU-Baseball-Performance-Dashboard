# Role-aware design navigation

The workspace sidebar, Home shortcuts, and profile Practice links use the verified 2026–27 roster role. Position players see Swing Design; pitchers see Pitch Design; explicitly `two_way` players see both. A recorded `P` in either position identifies a pitcher unless the roster explicitly identifies a two-way player. Known field positions may identify hitters when the type is absent. Missing seasons and unrecognized role/position information do not imply a hitter.

Effective Coaches and Admins retain both workspace tools and staff player selection. Player View As follows the selected player's current season; the actor's underlying Admin role does not restore staff links or a peer selector. Unlinked players see neither design link. Profile shortcuts use the displayed athlete's current-season role and retain that athlete's exact identity in the destination.

`loadDesignNavigation` reads only the effective linked athlete's `athlete_seasons` row with a fixed 2026–27 season and five identity/role fields through the ordinary authenticated Supabase client and existing RLS. Staff and unlinked players require no additional lookup. Query errors, missing rows, mismatched identities, and historical seasons hide the player shortcuts. React cache deduplicates the lookup only within the request render; no roster role or authorization is persisted in browser storage or a timed server cache. The client receives only two visibility booleans.

Navigation visibility is not authorization. Both design pages still require fresh presented access, reject invalid/peer athlete selectors before roster or measurement reads, select one exact athlete, and withhold measurements unless the current season supports the relevant discipline. Staff can open either tool, but a selected athlete with the wrong discipline receives its existing explanatory empty state. The browser-local import preview retains its existing navigation and does not gain protected design routes.

Fictional-only coverage lives in `tests/design-navigation.test.ts`, `tests/workspace-home.test.ts`, `tests/staff-athlete-search.test.ts`, both design page test files, and `tests/hitter-swing-blueprint.test.ts`. It checks effective Player View scope, both staff roles, hitter/pitcher/two-way links, unlinked/uncertain roles, current-season matching, minimal identity-scoped reads, and direct-route guards before measurement access.

The shared visual pass keeps Pacific red accents and official unmodified brand assets on charcoal/light-neutral surfaces. Home shortcuts wrap consistently for four, five, or seven links. Phone leaderboard previews stack into readable full-width cards; samples and explanatory captions stay visible. Staff Game Stats and profile summaries use larger secondary labels and wrapping mobile rate rows.

# Team Leaderboards

`/leaderboards` shows reviewed testing measurements in Physicality, Hitting and Throwing. Every active, configured Admin, Coach and Player—including Players without a profile link—can see the minimal team results. This is an explicitly authorized exception for leaderboards; ordinary roster, profile history and raw measurement reads retain their existing Player-own policies.

The page presents compact ranking cards with visible Rank, Athlete and Result columns and only Physicality, Hitting and Throwing category navigation; no metric/source/unit/period filters appear. Cards stack in two compact columns on wide screens and one column on phones. Each available metric selects one exact comparison automatically: prefer Fall, then the largest measured cohort, the metric’s preferred recorded unit order, and finally source name alphabetically. This is deterministic and never pools comparisons. Earlier body readings remain visible when no Fall comparison exists for that metric. The source and actual latest test date appear on each card, and each athlete’s own test date appears beside the result. The first ten results show immediately; an expandable continuation retains everyone else. Missing metrics are listed under Awaiting Testing without fabricated values. Selection details stay in collapsed About These Rankings notes.

Every card retains one metric, source/protocol, exact unit and testing period. Fall 2026 means September 1–December 31. Body metrics, including grip strength, also allow June 1–August 31 as a separate period. Timed agility tests appear in Physicality but remain Fall-only. Units and sources are never converted or pooled. Only measured members of the 2026–27 roster with null, active or redshirt status appear; no missing results are filled with zero. QPA/Pitching game snapshots remain in Game Stats and are not mixed into testing leaderboards.

Each athlete contributes the latest comparable observation by test date, then import time at millisecond precision, file hash and observation ID. This is the latest result, not the best historical result. Height ranks tallest first, Muscle Mass % highest first, and Body Fat % lowest first, as requested by the owner. Other higher-direction metrics sort descending; timed/lower-direction metrics sort ascending. Every measured result has a visible rank. Equal values share competition ranks (`1, 1, 3`) with stable permanent-code ordering and tied-rank labels that remain correct across the top-ten continuation. Body/spin values remain numerical comparisons without a health or performance rating. Leaderboard ordering is separate from the unchanged neutral profile percentile and strengths/weaknesses semantics. Height displays feet and inches rounded to one tenth of an inch, with the original reading in its title; stored values, source-unit separation and ranking order remain unchanged. Other direct readings display their exact stored numeric value; derived muscle percentage is marked approximate in the compact display and exposes its exact calculation value.

Muscle percentage is calculated only from one unambiguous compatible-unit weight and muscle-mass pair in the same canonical RENPHO report/date, with positive weight and muscle mass no greater than weight. A reported explicit percentage takes precedence. No synthetic raw observation is inserted. Leaderboards have no five-athlete minimum because minimal individual team results are authorized; profile percentile comparisons retain their separate minimum-five rule.

The Game Stats tab adds compact top-five tables and expandable remaining ranks. The owner-authorized signed-in game projection is separate from full game/profile access. QPA includes AVG, OBP, QPA%, HH%, HR, SB, batting BB%, K%, GDP. Pitching tables separate each actual game and show strikes/pitches, strikeouts, walks allowed and pitch count. Raw unrounded numbers determine ties/ranks; batting averages display three decimals. No PA qualification threshold is inferred; this is disclosed with opportunity bias.

Home Run Rate (HR%) uses recorded Pumps / PA × 100, with a positive denominator and HR no greater than PA or recorded hits. Profiles and the signed-in Game Stats leaderboard use the same exact-cohort percentiles. This measures home-run frequency; ISO/SLG/OPS still require doubles and triples.
